## Sobre a disciplina

Este repositório reúne materiais, registros e referências relacionados à disciplina de **Análise e Projeto de Sistemas (APS)**, integrante do curso de Engenharia de Software do Centro Universitário UDF.

A disciplina aborda técnicas, métodos e práticas para a análise e o projeto de sistemas de informação, com ênfase na orientação a objetos e na elaboração de artefatos utilizados durante o desenvolvimento de software.

O objetivo deste repositório é documentar as atividades acadêmicas, organizar referências e registrar a evolução dos conhecimentos adquiridos ao longo do semestre.

## Projeto acadêmico

Como parte das atividades da disciplina, foi desenvolvido um projeto em grupo com o objetivo de aplicar, na prática, os conceitos e métodos estudados em Análise e Projeto de Sistemas.

O desenvolvimento foi centralizado no repositório oficial do grupo, que reúne o código-fonte, a documentação e os demais materiais relacionados ao projeto.

### Repositório oficial do projeto

**[Acessar o projeto APS no GitHub](https://github.com/yagoa853-del/APS/tree/main)**

> **Organização do projeto:** o repositório oficial pertence a Yago Alves de Carvalho e é utilizado pelo grupo para centralizar o desenvolvimento e as entregas acadêmicas.

## Objetivos de aprendizagem

- Compreender as etapas de análise e projeto de sistemas de informação.
- Aplicar conceitos de orientação a objetos na modelagem de software.
- Identificar e elaborar artefatos utilizados na especificação de sistemas.
- Organizar a documentação técnica de um projeto de software.
- Aplicar os conhecimentos teóricos em um projeto colaborativo.
